# Chat Notification Sound

Place your notification sound file here as `notification.mp3`

## Instructions

1. Save your MP3 notification sound as: `notification.mp3`
2. Place it in this directory: `admin-dashboard/public/sounds/`
3. The file will be automatically played when new chat messages arrive

## Recommended Sound Properties

- Format: MP3
- Duration: 0.5 - 2 seconds
- Volume: Medium (will be played at 50% volume)
- File size: < 100KB for fast loading
